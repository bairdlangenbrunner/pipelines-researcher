Tiers: `docket` = same FERC docket; `strong` = near-identical name + operator/state; `related` = the EIA project name CONTAINS this row's name (typically an expansion/lateral of the same system — use it for context and history, never compare its values to this row without checking scope); `possible` = weaker name match with state + operator support. These are CANDIDATES from docket / name / operator / state matching. Confirm each is really this row's project (an operating mainline matches its own expansions; an expansion's capacity is INCREMENTAL, not the line's total) before using it. All EIA releases are ONE origin.
