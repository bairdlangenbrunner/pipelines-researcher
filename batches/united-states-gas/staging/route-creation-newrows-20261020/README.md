# Route creation for the new US gas rows: scope inventory (2026-10-20)

This folder is the review surface for the route creation pass over the 239 rows added to the Gas tab during the 2026 US gas cycle (P8091 to P8330) that have no geometry in the routes repo. Candidate routes land in `candidate_routes/` after Baird decides which maps to use (plan: `docs/plans/2026-10-20_us-gas-new-rows-route-creation.md`). Ten traced candidates (P8110, P8212, P8241, P8299, P8316, P8317, P8320, P8321, P8324, P8329) were built on 2026-10-20 from Baird's digitize picks and pass the validation gate; nothing is applied.

Files:

- `inventory.csv`: one line per routeless row with the research tier (A data center, B in development, C operating, D cancelled, blank or other status and not this pass, X no physical pipe), the oilandgaswatch.org match class, the suggested first rung on the source ladder, the seed refs copied from the sheet's `Status [ref]`, and two columns `map_status` and `decision` that the map hunt and Baird's review fill in (`decision` is prefilled for the 22 oilandgaswatch matches and the 5 tier X rows from Baird's 2026-10-20 rulings).
- `ogw_crosswalk.csv`: the 37 rows that have a record on oilandgaswatch.org, judged by hand (name, states and length compared). `direct` = the record's geometry is this pipeline; `part` = one part of a multi-part record is this pipeline (the note says which); `related` = the record is a different segment of the same system and its geometry is not this row's; `record-no-route` = the site tracks the project but has no geometry (its attached documents may still be the best map).
- `ogw_catalog.csv`: all 455 records of the site's pipeline table as pulled on 2026-10-20 through its data API (`POST https://oilandgaswatch.org/api/01-01_PIPELINES/query`, page size 1000), geometry omitted.
- `fetched_layers/ogw/<PID>_<record id>.geojson` (gitignored, re-fetchable): the geometry of every matched record, one LineString feature per part with the site's resolution, digitizer method and route source carried as properties.
- `maps/<PID>/`: what the map hunt found for each tier A and B row. `source.json` gives the row's `map_status`, each map file with its URL, document title, page, date read, fetch route, what it shows and its landmarks, a `searched` list and plain notes. Next to it are the downloaded documents (PDFs), the map pages rendered as PNG, and for P8318 the Texas Railroad Commission permit 10370 features as geojson. The gallery that shows these for Baird's picks is at https://claude.ai/artifact/DeavCcikQGM7vZJTgk5fvp.

- `traces/<PID>/`: the record of each digitized row (pixel trace, control points with their sources, fit report, notes and the scripts that ran). `fetched_layers/<PID>_traced.geojson` is the georeferenced line that went into the candidate. `packets/<PID>/` holds the rows that stopped for a data reason: P8092 (24 scanned sheets, no independent control points). For P8092 a Glenn Highway corridor proxy at very low accuracy was built on 2026-10-21 (`traces/P8092/NOTES.md`); it is not the surveyed alignment, P8261 and P8315 (no public route map). `traces/P8311/` holds the endpoint search for the Apollo South Pipeline: the end at the Apollo plant is sourced, the start at the Rover interconnect is not. With Baird's approval on 2026-10-20 an endpoints line was built from a proxy start at Cygnet Road and Wingston Road, at very low accuracy. It is shorter than the 23.5 miles the Teamsters notice states, and the state siting case letter of notification should replace it.
