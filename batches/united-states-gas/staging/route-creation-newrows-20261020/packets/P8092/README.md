This is a digitization packet for P8092, the Alaska Natural Gas Development Authority Glennallen to Palmer Spur Line, stated as 148 miles.
The map is Appendix A of the 2005 engineering report by Michael Baker Jr., Inc., 24 land use and ownership sheets (pages 2 to 25 of the PDF), fetched from the Alaska Resources Library and Information Services site.
The PDF is a scanned fax-quality raster, not a vector file, so the line cannot be extracted as a path.
Each sheet is its own strip map with its own pixel frame and its own orientation, so one trace and one fit cannot cover the whole line.
The route needs a separate fit per sheet, each with at least 6 independent ground control points, which is about 144 geocoded features in total.
The only locatable features printed on the sheets are the Universal Transverse Mercator grid labels, which come from the map itself and so cannot be used as independent control points under the project rule.
Creek and trail names on the sheets are mostly not in a public gazetteer at the precision needed, so a person should pick control points in QGIS from US Census place and county files and USGS hydrography.
The registration was not attempted, so no traced geometry exists for this row.
The suggested control point list in gcps.json has names and sources but no coordinates, because none were geocoded.
The best map is sheet 2 for the start and sheet 25 for the end near Palmer, with the milepost numbers on every sheet to check progress along the line.
