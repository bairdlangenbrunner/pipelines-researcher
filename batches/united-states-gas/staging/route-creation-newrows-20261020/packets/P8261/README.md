This is a digitization packet for P8261, Targa Bull Run II Pipeline, Texas, stated length 70 miles.

No usable public map of Bull Run II was found. A second search in October 2026 returned only the August 18, 2026 press release coverage, which gives the length and the Waha Hub but no route, counties, or plant sites.

The only map is page 11 of the Targa investor presentation from August 2026. It is a schematic with no roads, towns, or counties. It shows the earlier Bull Run extension of about 43 miles, not Bull Run II, and it predates the announcement.

The only fixed geographic features on the slide are the Waha marker and the New Mexico and Texas state line. That is far fewer than the six independent control points needed, so no trace was made.

The three new Delaware plants (Wrangler, Ranger and Ranger II) have no published location. A later Targa presentation or a Texas Railroad Commission permit may supply a route.
